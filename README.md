\# Deepfake Detection using Gated Spatio-Temporal Feature Fusion



A deepfake video detection project based on FaceForensics++ C40.



\## Dataset



FaceForensics++ C40 is used for experimentation.



The dataset is stored locally and is not uploaded to this repository.



\## Manipulations



\- Deepfakes

\- Face2Face

\- FaceSwap

\- NeuralTextures



\## Proposed Method



The project uses MobileNetV3 for spatial feature extraction and a gated spatio-temporal fusion mechanism for video-level deepfake classification.



\## Planned Experiments



\- Spatial-only baseline

\- Temporal GRU baseline

\- Spatial + Temporal concatenation

\- Gated spatio-temporal fusion

\- Ablation study

\- Unseen manipulation evaluation

\- Grad-CAM explainability

\- Efficiency evaluation

\- Streamlit application
